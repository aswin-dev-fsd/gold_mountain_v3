# UI, UX, Accessibility, Performance

Default UI standards:
- responsive from small to large screens
- keyboard accessible and screen-reader friendly
- semantic HTML and visible focus states
- clear loading, empty, error, and success states
- consistent spacing, typography, and interaction patterns
- avoid unnecessary animations and layout shift

Performance:
- measure before optimizing expensive paths when practical
- avoid unnecessary client-side JavaScript
- optimize images/fonts/assets using framework-native approaches
- watch bundle size, rendering strategy, network waterfalls, and repeated requests
