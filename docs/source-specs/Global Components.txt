DESIGN CONSISTENCY
- Use only #F7F3EA, #214D33, #C49A3A and #8F2D24.
- Use Outfit + The Seasons.
- Do not use blue/neon presentation colours.
- Do not turn every component into a card.
- Prefer editorial composition, whitespace and photography.

INTERACTION
- Buttons use subtle hover/focus states.
- Image reveals use transform/opacity/clip-path where practical.
- Complex scroll sequences use GSAP + ScrollTrigger only when justified.
- Respect prefers-reduced-motion.
- Mobile must have a non-drag/non-pinned equivalent for interactive content.

ACCESSIBILITY
- Semantic HTML first.
- Keyboard reachable controls.
- Visible focus states.
- Explicit form labels and useful errors.
- Pointer targets >= 24x24 CSS px where applicable.
- Do not rely on colour alone to convey meaning.
- Avoid focus being hidden behind sticky/floating UI.

CONTENT
- Never invent room details, prices, amenities, reviews, credentials or health claims.
- Use placeholders where client content is missing.
