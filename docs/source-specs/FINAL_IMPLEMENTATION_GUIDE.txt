2. FINAL BRAND SYSTEM
==================================================

COLOURS — LOCKED
Ivory  #F7F3EA
Green  #214D33
Gold   #C49A3A
Red    #8F2D24

Do not change any of these values.

Recommended role assignment:
Ivory — background / negative space
Green — primary text / navigation / major sections / primary button backgrounds
Gold — accent / divider / logo detail / selective display emphasis
Red — rare supporting accent

Accessibility constraints:
- Gold on Ivory is not sufficient for normal body text; do not use that combination for small text.
- Red on Green is not sufficient for normal text; do not use that combination.
- Use Green/Red on Ivory or Ivory on Green for primary readable text combinations.

TYPE
Primary: Outfit (brand guide label: "Outfit (Garet Alf)")
Secondary/editorial: The Seasons

Do not use Garet Sans as a separate substitute.
Do not implement "-60%" tracking literally.
Starting CSS tracking recommendations:
H1 -0.03em
H2 -0.025em
H3 -0.01em
Body 0

6. ANIMATION BLUEPRINT
==================================================

A. HERO — "ARRIVAL"
- Full-bleed real resort/landscape image
- Soft reveal mask
- Slow depth separation between foreground and background
- Headline enters after image settles
- Gold divider draws lightly
- CTA appears last
- No artificial loading screen

B. WELLNESS — "HEALING JOURNEY"
- Scroll-driven progression: BODY → MIND → FOOD → LIFESTYLE → ENVIRONMENT
- Use pinned composition only where desktop usability remains clear
- Mobile becomes sequential stacked sections

C. ARUNACHALA — "PRESENCE"
- Almost-static mountain
- Very small foreground movement
- Optional mist/light movement where source footage supports it
- Avoid aggressive zooms

D. DINING — "LAND TO TABLE"
- Farm image transitions to produce/garden/kitchen/table
- Prefer image masking and controlled horizontal motion over many cards

E. EXPERIENCE — "DISCOVERY"
- Horizontal storytelling rail on desktop
- Standard vertical storytelling on mobile
- Hover/active state reveals secondary information
- Keyboard alternative required if interaction uses dragging

F. STAY — "CHOOSE YOUR JOURNEY"
- Short Stay / Wellness Stay / Monthly Stay as distinct choices
- Hover or tap expands a panel with confirmed details
- Never animate unavailable price/inventory data

G. DAY TIMELINE — "A DAY AT GOLD MOUNTAIN"
- Optional homepage or experience module
- Scroll changes time-of-day visuals
- Keep text readable without animation

H. CTA MICRO-INTERACTIONS
- 2–6 px hover translation or subtle underline draw
- Avoid exaggerated magnetic effects on small-screen touch devices

I. SITE-WIDE TRANSITIONS
- Mostly opacity + translate + clip-path/image reveal
- Avoid animating layout properties repeatedly
- Avoid perpetual floating objects

==================================================
7. MOTION ACCESSIBILITY
==================================================

Implement:
@media (prefers-reduced-motion: reduce)

For reduced motion:
- Disable large parallax
- Disable large scale/pan effects
- Remove non-essential looping motion
- Replace timeline movement with static states/fades
- Keep essential content visible

Never make information inaccessible because animation is disabled.

==================================================
8. PERFORMANCE GATES
==================================================

Images:
- Use responsive sources
- Prefer AVIF/WebP with fallback
- Reserve dimensions/aspect ratios
- Prioritize actual LCP hero asset
- Lazy-load below-fold images

Fonts:
- WOFF2
- font-display: swap
- Load only required weights
- Avoid unnecessary third-party font requests

Animation:
- Prefer transform/opacity
- Avoid forced synchronous layout patterns
- Avoid heavy video backgrounds
- Keep JS bundles focused
- Clean up scroll triggers/listeners on component unmount

Quality target:
Treat strong Core Web Vitals and mobile performance as launch requirements.

==================================================
9. ACCESSIBILITY GATES
==================================================

Target WCAG 2.2 AA quality.

Required checks:
- Keyboard navigation works
- Focus is clearly visible
- Focus is not hidden by sticky/floating elements
- Interactive targets are at least 24x24 CSS px where applicable
- Heading hierarchy is logical
- Forms have explicit labels
- Error messages are understandable
- Decorative images have empty alt text
- Meaningful images have useful alt text
- No colour-only communication
- Reduced motion is respected

==================================================
10. CONTENT / CLAIMS GATES
==================================================

Never invent:
rooms, prices, package durations, inclusions, practitioners, certifications, awards, testimonials, ratings, medical claims, facilities, distance claims, availability or founder achievements.

Use placeholders:
[CONTENT TO BE PROVIDED BY CLIENT]
[PRICE TO BE PROVIDED]

Use wellness/experience language rather than guaranteed medical outcomes.

==================================================
11. INTERNATIONAL UX GATES
==================================================

Ensure visitors can quickly answer:
- What is Gold Mountain?
- Why should I stay here?
- What is the wellness offering?
- What is the difference between a stay and a wellness package?
- Where is it?
- How do I get there?
- What happens after I enquire?
- Who do I contact?

Do not assume local terminology is understood.
